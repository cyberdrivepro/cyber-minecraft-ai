How mod generation works

  1. Natural-language request → structured spec (Pydantic-validated)
  2. Procedural texture and asset generation
  3. Deterministic build engine (Bedrock .mcaddon / Fabric .jar)
  4. Strict validation + up to 3 automatic repair attempts
  5. Immutable version history (v1, v2, v3...) with conversational editing

Create and edit mods through the Telegram bot (/newmod, /edit) or via the REST API (/api/projects, /api/jobs/{id}). The dashboard lists projects and build jobs with live status.
