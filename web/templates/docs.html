Quick start

  1. Create a server under Create Server
  2. Upload real server software on the server's page (a server.jar for Java, or the official Bedrock .zip for Bedrock) — without an upload, servers run the embedded console runtime with real world/state files but no game protocol
  3. Press Start, wait for the queue, get your address
  4. Invite friends using the Networking tab address or share dashboard access under Sharing

Console commands

help · list · say <msg> · op / deop <player> · whitelist add|remove|list|on|off · ban / pardon <player> · kick <player> · time set day|night · weather clear|rain|thunder · difficulty <level> · seed · save-all · stop

Hosting modes explained

Embedded console runtime (default): manages real world files, properties, ops/whitelist/bans and the lifecycle, and implements the standard console command set in-process. It does not speak the Minecraft network protocol, so clients cannot join until real server software is uploaded.

Real Java runtime: once a server jar is uploaded and Java 17/21 is installed, the platform launches the actual process (java -jar server.jar nogui) and streams its real console output. Players join with the address from the Networking tab.

Real Bedrock runtime: upload the official Bedrock Dedicated Server zip; the platform extracts and runs bedrock_server (UDP).

Downloads & links

World exports and backups generate secure tokens valid for a limited time. Anyone with the link can download until it expires or is revoked — treat shared links like passwords. Manage your links from Download Links.

Troubleshooting

Server won't start? Check that Java is installed (System Diagnostics shows it), the EULA is accepted, and you are under the concurrency limit.
Friends can't connect? Run the Networking tab diagnostics. If SERVER_PUBLIC_HOST is not set the platform cannot verify public reachability — see docs/DEPLOYMENT.md for tunnel and DNS options.
Console shows "embedded console runtime"? No server software uploaded yet.
